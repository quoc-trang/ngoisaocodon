# Personal Portfolio Website

A modern, responsive personal portfolio website built with Nuxt.js 3 and Tailwind CSS.

## 🚀 Tech Stack

- **Framework**: Nuxt.js 3.15.0
- **Language**: TypeScript
- **Styling**: Tailwind CSS
- **Icons**: Nuxt Icon
- **Linting**: ESLint

## 🎨 Features

- Responsive design
- Modern UI with animations
- Dark mode support
- Social media integration
- Custom color scheme
- SEO friendly

## 🛠️ Development

### Prerequisites

- Node.js (Latest LTS version recommended)
- npm or yarn

### Installation

1. Clone the repository

```bash
git clone <repository-url>
cd quoc-trang
```

2. Install dependencies

```bash
npm install
```

3. Start development server

```bash
npm run dev
```

The application will be available at:

- Local: http://localhost:3000
- Network: http://[your-ip]:3000

### Development Tools

- **Nuxt DevTools**: Press `Shift + Option + D` in the browser
- **Tailwind Viewer**: Available at `http://localhost:3000/_tailwind/`

## 🎯 Project Structure

